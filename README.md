# Tactical Comms – פלאגין תקשורת ל-ATAK + שרת

פלאגין ל-ATAK שכל מי שמתקין אותו מתחבר לשרת שלך, ויכול:

| יכולת | איך זה עובד |
|---|---|
| 💬 **צ'אט** (הודעות טקסט) אחד-על-אחד ובקבוצה | דרך השרת. הודעות למשתמש שאינו מחובר נשמרות ונמסרות כשהוא מתחבר |
| 👥 **קבוצות שהמשתמשים פותחים בעצמם** | כל משתמש יוצר קבוצה, בוחר חברים, מוסיף ומסיר. אין צורך במנהל שרת |
| 🎙 **PTT (לחץ-ודבר) למשתמש** | שידור קול חי כל עוד הכפתור לחוץ, כמו מכשיר קשר |
| 📢 **PTT לכל הקבוצה** | כל החברים המחוברים שומעים. דובר אחד בכל רגע, והשרת מנהל את התור |
| 📍 **מיקומים על המפה** | כל משתמש מופיע כסמן ידידותי על מפת ATAK (כולל אות קריאה ואחוז סוללה) |
| 📞 **שיחות קוליות** | שיחה דו-כיוונית מלאה בין שני משתמשים: צלצול, מענה, דחייה, רמקול והשתקה |
| 📎 **העברת קבצים** | לכל משתמש או לכל קבוצה (עד 200MB כברירת מחדל) |

```
 ┌──────────── מכשיר Android ────────────┐                 ┌──────── השרת שלך ────────┐
 │ ATAK + Tactical Comms plugin          │  WSS (TLS)      │ כתובת IP, תעודה עצמית    │
 │  • צ'אט / קבוצות / PTT / שיחות        │◄──────────────►│   שהפלאגין נועל          │
 │  • סמנים על המפה (CoT פנימי)          │  HTTPS קבצים   │ Node.js relay server      │
 └───────────────────────────────────────┘                 │  • נתונים ב-/data (JSON)  │
                                                           └───────────────────────────┘
```

## מבנה התיקיות

```
server/   שרת Node.js (WebSocket + HTTP), סקריפט התקנה, Dockerfile, docker-compose, בדיקות
plugin/   פלאגין ATAK (Java), לפי מבנה ה-plugintemplate הרשמי של ATAK
docs/PROTOCOL.md   פרוטוקול התקשורת המלא בין הפלאגין לשרת
```

## 1. הקמת השרת

**מה צריך:** שרת לינוקס (VPS) עם כתובת IP ציבורית. **לא צריך דומיין.**

```bash
git clone <this repo> && cd tactical-comms/server
sudo bash install.sh
```

הסקריפט מתקין Docker אם חסר, יוצר מפתח גישה אקראי, מפעיל את השרת, ובסוף מדפיס את שלושת הדברים שצריך: **כתובת השרת**, **מפתח הגישה** ו**טביעת האצבע של התעודה**. צריך לוודא שפורט 443 (TCP) פתוח בחומת האש של השרת.

**איך זה מוצפן בלי דומיין:** תעודת HTTPS רגילה ניתנת רק לדומיין. לכן השרת יוצר לעצמו תעודה בהפעלה הראשונה, והפלאגין "נועל" אותה: בחיבור הראשון הוא שומר את טביעת האצבע שלה, ומאותו רגע מסרב להתחבר לשרת שמציג תעודה אחרת. כדי לוודא שהחיבור הראשון לא יורט, משווים את טביעת האצבע שמופיעה בהגדרות הפלאגין לזו שהסקריפט הדפיס. אפשר גם להזין אותה ידנית מראש.

הגדרות (בקובץ `.env`):

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `ACCESS_KEY` | נוצר אוטומטית | מפתח משותף שכל משתמש מזין בפלאגין. מי שאין לו את המפתח לא יכול להתחבר |
| `PORT` | 443 | הפורט שהשרת מאזין בו |
| `MAX_FILE_MB` | 200 | גודל קובץ מקסימלי |
| `FILE_TTL_HOURS` | 72 | אחרי כמה זמן קבצים נמחקים מהשרת |
| `PTT_MAX_SECONDS` | 90 | אורך שידור PTT מקסימלי |

- **אם התקנת את השרת מחדש** (ונמחק ה-volume של Docker), נוצרת תעודה חדשה. כל משתמש צריך למחוק את שדה טביעת האצבע בהגדרות הפלאגין ולהתחבר שוב.
- **עם דומיין:** אם בעתיד תרצה דומיין ותעודה ציבורית, מגדירים `DOMAIN` ב-`.env` ומריצים `docker compose -f docker-compose.domain.yml up -d --build`.
- **הרצה בלי Docker (לבדיקות):** `cd server && npm install && ACCESS_KEY=test TLS_SELF_SIGNED=1 npm start`, שמאזין בפורט 8080.

## 2. בניית הפלאגין

הפלאגין נבנה מול **ה-ATAK-CIV SDK הציבורי בגרסה 4.6.0.5**, שמפורסם ב-GitHub. לא צריך הרשמה ל-tak.gov.

**אוטומטית (מומלץ):** בכל שינוי בתיקייה `plugin/`, ‏GitHub Actions בונה את הפלאגין. נכנסים ללשונית **Actions** בריפו, פותחים את ההרצה האחרונה של **Build ATAK plugin**, ומורידים מתחתית העמוד (Artifacts) שני קבצים:

- `tactical-comms-plugin`: ה-APK של הפלאגין.
- `atak-developer-build-4.6.0.5`: גרסת הפיתוח של ATAK, שמתקינים על הטלפונים **במקום** ATAK מ-Google Play.

**ידנית, על המחשב שלך** (צריך JDK 11 ו-Android SDK):

```bash
cd plugin
./setup-sdk.sh                 # מוריד את ה-SDK ומכין את local.properties
./gradlew assembleCivDebug     # ה-APK נוצר ב-app/build/outputs/apk/civ/debug/
```

> ⚠️ **הפלאגין הזה עובד רק עם גרסת הפיתוח של ATAK 4.6**, ולא עם ATAK מ-Google Play. ATAK מהחנות טוען רק פלאגינים שנחתמו ב-TAK.gov. גרסת הפיתוח מדלגת על בדיקת החתימה, ולכן כל המשתמשים צריכים להתקין אותה. אי אפשר להתקין אותה מעל ATAK מהחנות, אז קודם מסירים אותו.

> מפתח החתימה `plugin/debug-signing.jks` שמור בריפו עם סיסמה גלויה. הוא משמש רק כדי שעדכוני הפלאגין יותקנו זה מעל זה, ואינו מנגנון אבטחה.

## 3. התקנה ושימוש

1. מתקינים על המכשיר את גרסת הפיתוח של ATAK ואת ה-APK של הפלאגין. ב-ATAK: **Settings → Plugins** (או Plugin Manager), ומסמנים את Tactical Comms לטעינה.
2. בסרגל הכלים של ATAK מופיע כפתור **Tactical Comms**. לוחצים עליו, ואז על **⚙**:
   - **Server address:** כתובת ה-IP של השרת, למשל `203.0.113.10` (אם הפורט אינו 443: `203.0.113.10:8443`)
   - **Access key:** המפתח שהסקריפט הדפיס
   - **Server certificate fingerprint:** משאירים ריק. אחרי החיבור הראשון השדה מתמלא לבד, וכדאי להשוות אותו לערך שהסקריפט הדפיס
3. **Save & connect.** אות הקריאה וה-UID נלקחים אוטומטית מ-ATAK.
4. בפעם הראשונה ATAK יבקש הרשאת מיקרופון (נדרשת ל-PTT ולשיחות).

**בתוך הפאנל:**
- **Contacts:** כל המשתמשים (מחוברים קודם), מרחק וסוללה. כפתורים: 💬 צ'אט, 📍 הצג על המפה, 📞 שיחה, 📎 קובץ, ו-**🎙 Hold to talk** (מחזיקים לחוץ = משדרים, משחררים = סיום).
- **Groups:** **＋ New group**: שם ובחירת חברים. לכל קבוצה יש צ'אט, קובץ, ניהול (הוספה/הסרה/שינוי שם/עזיבה) ו-PTT לכל הקבוצה.
- **Chats:** כל השיחות, עם מונה הודעות שלא נקראו. בתוך שיחה יש גם כפתור PTT.
- הודעה שנכשלה (⚠) נשלחת שוב בלחיצה עליה. קבצים שהתקבלו נשמרים ב-`atak/tools/tacticalcomms/received/`.

## 4. אבטחה ופרטיות: מה כדאי לדעת

- כל התעבורה מוצפנת ב-TLS בין המכשיר לשרת. **אין הצפנה מקצה-לקצה:** השרת שלך יכול טכנית לראות את התוכן. זה מקובל כשהשרת בבעלותך, אבל כדאי לדעת.
- ההרשאה מבוססת על מפתח משותף אחד. מי שיש לו את המפתח יכול להתחבר ולראות את מיקומי כולם. אם המפתח דלף, מחליפים `ACCESS_KEY` ומפעילים מחדש.
- כל משתמש מחובר רואה את המיקום של כל השאר. אפשר לכבות שיתוף מיקום בהגדרות (`Share my location`).

## 5. פרטים טכניים

- **קול:** G.711 µ-law, 8kHz (בערך 64 kbit/s לכל דובר), עם ביטול הד והפחתת רעש של Android. מכוון ל-LTE/Wi-Fi ולא לרשתות צרות מאוד. אפשר להחליף ל-Opus בהמשך כדי לחסוך רוחב פס.
- **שיחות ו-PTT עוברים דרך השרת** (relay), כך שזה עובד מאחורי כל NAT בלי שרתי STUN/TURN.
- **מיקומים** מוזרקים ל-ATAK כאירועי CoT פנימיים (`a-f-G-U-C`) עם קידומת UID ‏`tc-`, כדי לא להתנגש בסמנים שמגיעים מ-TAK Server.
- **שמירת נתונים:** בשרת ב-`/data/state.json` (משתמשים, קבוצות, הודעות ממתינות), ובמכשיר ב-`atak/tools/tacticalcomms/chats.json`.

## 6. מה נבדק

- **שרת:** בדיקת end-to-end אוטומטית (`cd server && npm test`) שמכסה הרשאה, נוכחות, מיקומים, צ'אט ישיר וקבוצתי, יצירה וניהול של קבוצות והרשאות, PTT כולל תור דוברים, שיחות (busy / no answer / hangup), העלאה והורדה של קבצים כולל הרשאות, ותור הודעות לא-מחוברים.
- **פלאגין:** כל הקוד עובר קומפילציה מול Android framework אמיתי (API 34) וספריית Java-WebSocket האמיתית, וגם מול `main.jar` האמיתי של ATAK 4.6.0.5. בנוסף, קוד ה-codec ובניית הפריימים של הפלאגין נבדקו מול השרת האמיתי (שידור PTT ו-צ'אט בעברית עברו מקצה לקצה).
- **חיבור לפי IP:** נעילת התעודה של הפלאגין נבדקה מול השרת האמיתי: חיבור ראשון שומר את טביעת האצבע הנכונה, טביעה נכונה מתקבלת, טביעה שגויה נדחית, וגם העברת הקבצים עוברת באותה נעילה.
- **בנייה:** ה-APK נבנה בהצלחה ב-GitHub Actions מול ה-SDK האמיתי של ATAK 4.6.0.5.
- **מה לא נבדק:** סקריפט ההתקנה ותמונת ה-Docker לא הורצו (אין כאן Docker פעיל), רק הקוד שבתוכם. הפלאגין **לא הורץ על מכשיר עם ATAK** (אין כאן מכשיר). צריך להתקין ולבדוק על טלפונים. כנראה יהיו התאמות קטנות בממשק, וזה צפוי.
