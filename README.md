# Tactical Comms – פלאגין תקשורת ל-ATAK + שרת

פלאגין ל-ATAK שכל מי שמתקין אותו מתחבר לשרת שלך, ויכול:

| יכולת | איך זה עובד |
|---|---|
| 💬 **צ'אט** (הודעות טקסט) אחד-על-אחד ובקבוצה | דרך השרת. הודעות למשתמש שאינו מחובר נשמרות ונמסרות כשהוא מתחבר |
| 👥 **קבוצות שהמשתמשים פותחים בעצמם** | כל משתמש יוצר קבוצה, בוחר חברים, מוסיף ומסיר. אין צורך במנהל שרת |
| 🎙 **PTT (לחץ-ודבר) למשתמש** | שידור קול חי כל עוד הכפתור לחוץ, כמו מכשיר קשר |
| 📢 **PTT לכל הקבוצה** | כל החברים המחוברים שומעים. דובר אחד בכל רגע, והשרת מנהל את התור |
| 📍 **מיקומים על המפה** | כל משתמש מופיע כסמן ידידותי על מפת ATAK (כולל אות קריאה ואחוז סוללה) |
| 📞 **שיחות קוליות** | שיחה דו-כיוונית מלאה בין שני משתמשים: צלצול, מענה, דחייה, רמקול והשתקה |
| 📎 **העברת קבצים** | לכל משתמש או לכל קבוצה (עד 200MB כברירת מחדל) |

```
 ┌──────────── מכשיר Android ────────────┐                 ┌──────── השרת שלך ────────┐
 │ ATAK + Tactical Comms plugin          │  WSS (TLS)      │ Caddy (תעודת HTTPS       │
 │  • צ'אט / קבוצות / PTT / שיחות        │◄──────────────►│   אוטומטית)              │
 │  • סמנים על המפה (CoT פנימי)          │  HTTPS קבצים   │ Node.js relay server      │
 └───────────────────────────────────────┘                 │  • נתונים ב-/data (JSON)  │
                                                           └───────────────────────────┘
```

## מבנה התיקיות

```
server/   שרת Node.js (WebSocket + HTTP), Dockerfile, docker-compose עם Caddy ל-HTTPS, בדיקות
plugin/   פלאגין ATAK (Java), לפי מבנה ה-plugintemplate הרשמי של ATAK
docs/PROTOCOL.md   פרוטוקול התקשורת המלא בין הפלאגין לשרת
```

## 1. הקמת השרת

**מה צריך:** שרת לינוקס (VPS) עם Docker, ושם דומיין שמצביע לכתובת ה-IP שלו (רשומת A), עם פורטים 80 ו-443 פתוחים.

```bash
git clone <this repo> && cd tactical-comms/server
cp .env.example .env
nano .env        # הגדר ACCESS_KEY (מפתח ארוך ואקראי) ו-DOMAIN (למשל comms.mydomain.com)
docker compose up -d --build
```

זהו. Caddy מוציא תעודת HTTPS אוטומטית. בדיקה: `https://comms.mydomain.com/health`.

הגדרות (בקובץ `.env`):

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `ACCESS_KEY` | (חובה) | מפתח משותף שכל משתמש מזין בפלאגין. מי שאין לו את המפתח לא יכול להתחבר |
| `DOMAIN` | (חובה) | הדומיין של השרת |
| `MAX_FILE_MB` | 200 | גודל קובץ מקסימלי |
| `FILE_TTL_HOURS` | 72 | אחרי כמה זמן קבצים נמחקים מהשרת |
| `PTT_MAX_SECONDS` | 90 | אורך שידור PTT מקסימלי |

הרצה בלי Docker (לבדיקות): `cd server && npm install && ACCESS_KEY=test npm start`, שמאזין ב-`ws://<ip>:8080/ws`.

## 2. בניית הפלאגין

פלאגינים ל-ATAK נבנים מול **ה-ATAK SDK הרשמי**. הוא לא ציבורי ב-Maven, ומורידים אותו בחינם מ-[tak.gov](https://tak.gov) (צריך הרשמה).

1. הורד את ה-ATAK-CIV SDK שמתאים לגרסת ה-ATAK שמותקנת אצל המשתמשים, ופתח אותו.
2. העתק את התיקייה `plugin/` לתוך `<SDK>/plugins/TacticalComms`.
3. העתק `local.properties.example` ל-`local.properties` ומלא את הנתיבים: Android SDK ו-keystore מה-SDK.
4. ב-`app/build.gradle` עדכן את `ATAK_VERSION` לגרסת ה-SDK.
   אם ה-SDK שלך חדש מ-4.6, הכי בטוח להעתיק את `build.gradle` (שני הקבצים) מה-plugintemplate שבתוך ה-SDK שלך, ולהוסיף לו רק את השורה:
   `implementation 'org.java-websocket:Java-WebSocket:1.5.7'`
5. בנייה: `./gradlew assembleCivDebug`. ה-APK נוצר ב-`app/build/outputs/apk/civ/debug/`.

> ⚠️ **חשוב: חתימה.** ATAK-CIV מחנות Google Play טוען רק פלאגינים **שנחתמו על ידי TAK.gov** (שולחים את קוד המקור לתהליך החתימה שלהם). לפיתוח ולבדיקות משתמשים בגרסת ה-ATAK שמגיעה עם ה-SDK, שטוענת גם פלאגינים בחתימת debug. להפצה למשתמשים עם ATAK מהחנות צריך לעבור את תהליך החתימה של TAK.gov.

## 3. התקנה ושימוש

1. מתקינים את ה-APK על המכשיר (לצד ATAK). ב-ATAK: **Settings → Plugins** (או Plugin Manager), ומסמנים את Tactical Comms לטעינה.
2. בסרגל הכלים של ATAK מופיע כפתור **Tactical Comms**. לוחצים עליו, ואז על **⚙**:
   - **Server address:** `comms.mydomain.com` (או `wss://comms.mydomain.com`)
   - **Access key:** המפתח מ-`.env`
3. **Save & connect.** אות הקריאה וה-UID נלקחים אוטומטית מ-ATAK.
4. בפעם הראשונה ATAK יבקש הרשאת מיקרופון (נדרשת ל-PTT ולשיחות).

**בתוך הפאנל:**
- **Contacts:** כל המשתמשים (מחוברים קודם), מרחק וסוללה. כפתורים: 💬 צ'אט, 📍 הצג על המפה, 📞 שיחה, 📎 קובץ, ו-**🎙 Hold to talk** (מחזיקים לחוץ = משדרים, משחררים = סיום).
- **Groups:** **＋ New group**: שם ובחירת חברים. לכל קבוצה יש צ'אט, קובץ, ניהול (הוספה/הסרה/שינוי שם/עזיבה) ו-PTT לכל הקבוצה.
- **Chats:** כל השיחות, עם מונה הודעות שלא נקראו. בתוך שיחה יש גם כפתור PTT.
- הודעה שנכשלה (⚠) נשלחת שוב בלחיצה עליה. קבצים שהתקבלו נשמרים ב-`atak/tools/tacticalcomms/received/`.

## 4. אבטחה ופרטיות: מה כדאי לדעת

- כל התעבורה מוצפנת ב-TLS בין המכשיר לשרת (דרך Caddy). **אין הצפנה מקצה-לקצה:** השרת שלך יכול טכנית לראות את התוכן. זה מקובל כשהשרת בבעלותך, אבל כדאי לדעת.
- ההרשאה מבוססת על מפתח משותף אחד. מי שיש לו את המפתח יכול להתחבר ולראות את מיקומי כולם. אם המפתח דלף, מחליפים `ACCESS_KEY` ומפעילים מחדש.
- כל משתמש מחובר רואה את המיקום של כל השאר. אפשר לכבות שיתוף מיקום בהגדרות (`Share my location`).

## 5. פרטים טכניים

- **קול:** G.711 µ-law, 8kHz (בערך 64 kbit/s לכל דובר), עם ביטול הד והפחתת רעש של Android. מכוון ל-LTE/Wi-Fi ולא לרשתות צרות מאוד. אפשר להחליף ל-Opus בהמשך כדי לחסוך רוחב פס.
- **שיחות ו-PTT עוברים דרך השרת** (relay), כך שזה עובד מאחורי כל NAT בלי שרתי STUN/TURN.
- **מיקומים** מוזרקים ל-ATAK כאירועי CoT פנימיים (`a-f-G-U-C`) עם קידומת UID ‏`tc-`, כדי לא להתנגש בסמנים שמגיעים מ-TAK Server.
- **שמירת נתונים:** בשרת ב-`/data/state.json` (משתמשים, קבוצות, הודעות ממתינות), ובמכשיר ב-`atak/tools/tacticalcomms/chats.json`.

## 6. מה נבדק

- **שרת:** בדיקת end-to-end אוטומטית (`cd server && npm test`) שמכסה הרשאה, נוכחות, מיקומים, צ'אט ישיר וקבוצתי, יצירה וניהול של קבוצות והרשאות, PTT כולל תור דוברים, שיחות (busy / no answer / hangup), העלאה והורדה של קבצים כולל הרשאות, ותור הודעות לא-מחוברים.
- **פלאגין:** כל הקוד עובר קומפילציה מול Android framework אמיתי (API 34) וספריית Java-WebSocket האמיתית, כש-API של ATAK מוחלף בגרסאות stub שהחתימות שלהן נבדקו מול קוד המקור הציבורי של ATAK-CIV. בנוסף, קוד ה-codec ובניית הפריימים של הפלאגין נבדקו מול השרת האמיתי (שידור PTT ו-צ'אט בעברית עברו מקצה לקצה).
- **מה לא נבדק:** הפלאגין **לא הורץ על מכשיר עם ATAK** (אין כאן ATAK SDK או מכשיר). צריך לבנות אותו מול ה-SDK ולבדוק על מכשירים. כנראה יהיו התאמות קטנות בממשק, וזה צפוי.
